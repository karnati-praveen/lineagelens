    GitHub CI Integration

    Risk Gate Configuration

    GitHub Actions Workflow Snippet

    Add this step to your workflow file and set LINEAGELENS_API_KEY in repository secrets.

    - name: LineageLens Risk Check
  uses: actions/github-script@v7
  with:
    script: |
      const { execSync } = require('child_process');
      const files = execSync('git diff --name-only HEAD~1').toString().trim().split('\n');
      const apiKey = process.env.LINEAGELENS_API_KEY;
      const base = process.env.LINEAGELENS_URL;
      let maxRisk = 0; let failed = false;
      for (const f of files) {
        if (!/\.(py|js|ts|tsx|jsx|java|go|rs)$/.test(f)) continue;
        const code = require('fs').readFileSync(f,'utf8');
        const r = await fetch(`${base}/github/check`,{method:'POST',headers:{'Content-Type':'application/json','X-API-Key':apiKey},body:JSON.stringify({code,file_path:f})});
        const j = await r.json();
        if (j.riskScore > maxRisk) maxRisk = j.riskScore;
        if (!j.passed) failed = true;
        core.info(`${f}: ${j.riskScore} ${j.passed?'✅':'❌'}`);
      }
      if (failed) core.setFailed(`Risk gate failed (max score ${maxRisk})`);
  env:
    LINEAGELENS_API_KEY: ${{ secrets.LINEAGELENS_API_KEY }}
    LINEAGELENS_URL: ${{ secrets.LINEAGELENS_URL }}
    MCP Server — Connect AI Assistants

    What this is

    The Model Context Protocol (MCP) server lets your AI assistants — Claude Code, Cursor, Continue, and any other MCP-capable client — query LineageLens's provenance history directly.

    • "What AI-generated code touched auth/ this week?"
    • "Show me every Claude Sonnet insertion in payments.py."
    • "Which model produced the highest-risk edits in the last 7 days?"

    All queries are scoped to your current workspace. Nothing leaves your network.

    Step 1 — Your backend URL

    Step 2 — Generate an API key

    The MCP server authenticates to the backend using an API key. Generate one with the scopes provenance:read at minimum.

    Admins: open the Team tab → API Keys section → Generate API Key.

    Non-admins can also use their personal access token (set LINEAGELENS_USERNAME + LINEAGELENS_PASSWORD in the MCP env instead).
