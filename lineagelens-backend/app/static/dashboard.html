GitHub CI Integration

Risk Gate Configuration

GitHub Actions Workflow Snippet

Add this step to your workflow file and set LINEAGELENS_API_KEY in repository secrets.

- name: LineageLens Risk Check
  uses: actions/github-script@v7
  with:
    script: |
      const { execSync } = require('child_process');
      const files = execSync('git diff --name-only HEAD~1').toString().trim().split('\n');
      const apiKey = process.env.LINEAGELENS_API_KEY;
      const base = process.env.LINEAGELENS_URL;
      let maxRisk = 0; let failed = false;
      for (const f of files) {
        if (!/\.(py|js|ts|tsx|jsx|java|go|rs)$/.test(f)) continue;
        const code = require('fs').readFileSync(f,'utf8');
        const r = await fetch(`${base}/github/check`,{method:'POST',headers:{'Content-Type':'application/json','X-API-Key':apiKey},body:JSON.stringify({code,file_path:f})});
        const j = await r.json();
        if (j.riskScore > maxRisk) maxRisk = j.riskScore;
        if (!j.passed) failed = true;
        core.info(`${f}: ${j.riskScore} ${j.passed?'✅':'❌'}`);
      }
      if (failed) core.setFailed(`Risk gate failed (max score ${maxRisk})`);
  env:
    LINEAGELENS_API_KEY: ${{ secrets.LINEAGELENS_API_KEY }}
    LINEAGELENS_URL: ${{ secrets.LINEAGELENS_URL }}
MCP Server — Connect AI Assistants

What this is

The Model Context Protocol (MCP) server lets your AI assistants — Claude Code, Cursor, Continue, and any other MCP-capable client — query LineageLens's provenance history directly. Once configured, you can ask your assistant questions like:

  • "What AI-generated code touched auth/ this week?"
  • "Show me every Claude Sonnet 4.6 insertion in payments.py."
  • "Which model produced the highest-risk edits in the last 7 days?"
  • "Explain provenance record 7a3e9b2c-... in plain English."

All queries are scoped to your current workspace. Nothing leaves your network.

Step 1 — Your backend URL

The MCP server connects to this LineageLens backend. Make sure it's reachable from wherever the MCP client runs (usually your local machine).

Step 2 — Generate an API key

The MCP server authenticates to the backend using an API key. Generate one with the scopes provenance:read at minimum.

Admins: open the Team tab → API Keys section → Generate API Key. Copy the key once shown — it cannot be retrieved later.

Non-admins can also use their personal access token (set LINEAGELENS_USERNAME + LINEAGELENS_PASSWORD in the MCP env instead).

Step 3 — Paste this into your AI client's config

Replace YOUR_API_KEY_HERE with the key you generated. Replace the script path with where you cloned LineageLens.

Available tools

        
Your AI client can call any of these once connected:

        

          
ToolWhat it does

          
            
search_provenanceFind AI-generated code by keyword, model, file path, or date range. Returns up to 50 records per call.

            
get_recordFetch the full provenance record for a UUID — prompt, model, file, edit, status, risk score, and metadata.

            
list_recentRecent AI insertions (newest first). Useful for "what did AI do today" queries.

            
check_file_riskRisk profile for a specific file — distribution of critical / high / medium / low insertions.

            
get_insightsWorkspace governance summary — total records, prompt-capture rate, top models, top files.

            
explain_recordPlain-English explanation of a record. Uses the backend's configured explainer LLM.

            
list_workspacesLists workspaces your token can access. Useful when one user belongs to multiple teams.

          
        

      


      

        
Step 4 — Verify it works

        
Restart your AI client after pasting the config. Then ask it:

        
Using LineageLens, list my 5 most recent AI-generated code insertions.

        
If it works, you'll see real captures pulled from this dashboard. If you see "MCP server not found" or "tool not available", check that:

        
    
          
  • The script path in the config is correct (it must be the absolute path to lineagelens-mcp/lineagelens-mcp.py)
    • 
          
  • Your client was fully restarted, not just reloaded
    • 
          
  • The API key has at least provenance:read scope
    • 
          
  • The backend at the URL above is reachable from the client's machine
    • 
        

      


      

        
Privacy & data flow

        
    
          
  • The MCP server is a local subprocess spawned by your AI client. It does not open a network listener.
    • 
          
  • All queries are scoped to your workspace via the API key.
    • 
          
  • The MCP server connects to your LineageLens backend. Nothing is sent to Anthropic, OpenAI, Google, or any third party.
    • 
          
  • If you remove an API key (Team → API Keys → Revoke), the MCP server returns 401 within its next request and your AI client loses access.
