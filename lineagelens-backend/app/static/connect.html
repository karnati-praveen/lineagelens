Manual Configuration

If connecting manually or configuring CI/CD headless runners, use these configuration parameters.

// In .vscode/settings.json
{
  "aiCodeProvenance.mode": "backend",
  "aiInsertionDetector.backend.baseUrl": ""
}
// In .vscode/settings.json
{
  "lineagelensBase.backendUrl": ""
}
export LINEAGELENS_BACKEND_URL=
export ANTHROPIC_BASE_URL=http://localhost:8788
export OPENAI_BASE_URL=http://localhost:8788
