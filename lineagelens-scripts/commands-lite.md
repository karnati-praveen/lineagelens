# LineageLens Lite — Commands Reference

## Start / Stop

```bash
# Start (first run opens the setup wizard automatically)
bash quickstart.sh

# Stop
docker compose -f lineagelens-deploy/docker-compose.lite.yml down

# Restart
docker compose -f lineagelens-deploy/docker-compose.lite.yml restart
```

## Logs

```bash
docker compose -f lineagelens-deploy/docker-compose.lite.yml logs -f
```

## Reset (wipe all data)

```bash
bash reset.sh
```

## Upgrade

```bash
docker compose -f lineagelens-deploy/docker-compose.lite.yml pull
docker compose -f lineagelens-deploy/docker-compose.lite.yml up -d
```

## URLs

| Resource | URL |
|---|---|
| Dashboard | http://localhost:8787/dashboard |
| Setup wizard | http://localhost:8787/setup |
| API docs | http://localhost:8787/docs |
| Health check | http://localhost:8787/health |

## Environment variables (lineagelens-deploy/.env)

| Variable | Required | Default | Description |
|---|---|---|---|
| `JWT_SECRET_KEY` | Yes | — | Random secret, auto-generated by quickstart.sh |
| `DATABASE_URL` | No | `sqlite+aiosqlite:///./data/lineagelens.db` | SQLite path inside container |
| `APP_ENV` | No | `production` | Set to `development` for debug mode |
